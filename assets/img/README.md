# Zdjęcia — instrukcja

Wrzuć pliki dokładnie pod tymi nazwami. Strona używa ścieżek względnych
(`assets/img/...`). Dopóki pliku nie ma, strona pokazuje gładki, rozmyty
placeholder w kolorze tła (nie ikonę zepsutego obrazka).

## Wymagane pliki

| Nazwa pliku          | Co to jest                                                        |
|----------------------|-------------------------------------------------------------------|
| `logo.png`           | Logo studia (najlepiej PNG z przezroczystym tłem)                 |
| `realizacja_01.jpg`  | Najjaśniejsze, najbardziej reprezentacyjne zdjęcie — trafia też do HERO |
| `realizacja_02.jpg`  | Galeria                                                           |
| `realizacja_03.jpg`  | Galeria                                                           |
| `realizacja_04.jpg`  | Galeria                                                           |
| `realizacja_05.jpg`  | Galeria                                                           |
| `realizacja_06.jpg`  | Galeria                                                           |

## Logo

Spośród przesłanych grafik logiem jest ta z napisem **„MW BALTIC DESIGN"**
oraz monogramem M / L na złoto‑grafitowym gradiencie. Zapisz ją jako
`logo.png`. Najlepiej wyeksportować samo logo na przezroczystym tle, żeby
ładnie usiadło w przezroczystej nawigacji.

## Wskazówka

`realizacja_01.jpg` pokazuje się w HERO w kadrze pionowym 4:5, więc wybierz
zdjęcie, które dobrze wygląda w pionie i jest jasne.
